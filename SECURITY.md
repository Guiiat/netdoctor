# Security Policy

## Supported versions

Until NetDoctor reaches `1.0`, security fixes are provided for the latest released minor version.

## Reporting a vulnerability

Please do not open a public issue for credential leakage, command injection, unsafe network behavior,
or another suspected vulnerability. Use GitHub's **Report a vulnerability** private advisory feature
for this repository. If private advisories are unavailable, contact the repository owner through the
private address listed on their GitHub profile.

Include a minimal reproduction, affected version, platform, and impact. Replace every real credential,
private hostname, IP address, username, and home path with an obvious placeholder. You should receive
an acknowledgement within seven days.

## 安全问题报告

如果发现凭据泄漏、命令注入、不安全网络行为等漏洞，请不要创建公开 Issue。优先使用本仓库
GitHub **Report a vulnerability** 私密安全公告；如果该功能不可用，请通过仓库所有者 GitHub
主页提供的私密联系方式报告。

请附上最小复现、受影响版本、平台和影响范围，并将真实凭据、内网域名、IP、用户名和主目录
替换为明显的占位符。维护者应在七天内确认收到。
